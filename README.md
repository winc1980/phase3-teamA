# 早稲田大学特化型 単位レビューサイト（仮）

> phase3の進め方は [docs/README.md](docs/README.md) を見てください。

## 何を作るか（1文）
早稲田の授業の口コミ・評価を、つぶやくくらいの軽さで見たり書いたりできるWebアプリ。

## 誰が使うか
- 履修登録の前に、どの授業を取るか迷っている早大生（特に知り合いが少なく、先輩に聞けない1年生）
- 取った授業の感想を気軽に残したい早大生

## MVP（phase3の間に作りきる最小の姿）
1. 学部・曜日・時限などのカテゴリや、キーワードで授業を探せる
2. 授業の詳細と、評価（単位の取りやすさ・先生の厳しさなど）・コメントを**ログインなしで**見られる
3. ログインした早大生が、評価・コメントを投稿できる
4. 自分の投稿を編集・削除できる

## やらないこと
<!-- 3つ書けると、作るものが途中で膨らみにくくなります -->
1. 画像・動画のアップロード
2. 早稲田生以外の投稿（投稿は早稲田メールのアカウントに限る）
3. シラバスの自動取り込み（規約を確認するまでは、授業データは手で入れる）

## 技術スタック

| 部分 | 採用 | 理由 |
|---|---|---|
| 言語 | TypeScript | 型があるので書き間違いに早く気づける |
| フロントエンド／バックエンド | Next.js | 画面と裏側の処理を1つにまとめて管理を楽にする |
| データベース | PostgreSQL（Neon） | 表の形でデータを扱う定番。DBだけのサービスなので、ログインや権限の仕組みを自分たちで書いて理解できる |
| DB操作 | Drizzle | TypeScriptでDBを扱え、表の設計をファイルでGit管理できる |
| ログイン | Auth.js | Googleログイン＋メールアドレスの確認で、早稲田生だけが投稿できるようにする |
| 公開 | Vercel | GitHubにpushするだけで公開できる |

採用しなかったもの：Supabase（ログイン・権限の肩代わりが多く、仕組みが見えにくいため）、Cloudflare R2 / S3（MVPに画像アップロードがないため）、CDN（Vercelに内蔵）
